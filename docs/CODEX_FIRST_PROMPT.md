# First Codex prompt: design review only

Paste this into Codex once the repository files are in place.

```
Read AGENTS.md, docs/PRD.md, design/DESIGN_BRIEF.md, design/REFERENCES.md and design/tokens.css, and look at the images in design/references/.

Do not write application code yet. Do not copy any reference site. Do not invent article facts. Ask before changing the stack or adding dependencies.

1. Summarise the visual direction in your own words, in five sentences.
2. List the design tokens and the four font families you will use.
3. Identify any contradictions between the PRD, the design brief, the references and AGENTS.md. If there are none, say so.
4. Propose a desktop front-page wireframe and a mobile reading order in plain text.
5. Propose the smallest first task: scaffolding the Next.js project with a /tokens showcase page and a Playwright screenshot script.
6. List anything you need from me before starting (for example the Robert Tran reference screenshot).
```

Expect a short written response only. If it proposes changes you disagree with, answer in the same session before moving on to the first build prompt (0.1) in the Build Guide.
